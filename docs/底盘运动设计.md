# 底盘运动设计



## 1\. 轮子选择



### 1\.1 需求分析与初步验证



我们首先对比赛场地进行了尺寸分析，并对1:2的坡道（高30cm，长60cm，角度约26\.5°）进行了实物模型还原。在实际搭建测试中，我们发现该坡道比官方文档的视觉呈现效果要**陡峭得多**，且场地表面（由5mm板材构成）较为**光滑**。因此，轮子选型的第一优先级确定为：**必须具备极强的抓地力与摩擦力，以防止打滑和失控。**

### 1\.2 轮子选型对比与淘汰过程



在满足抓地力需求的前提下，我们对比了以下几种常见的机器人底盘构型，并进行了逐一淘汰：



- **四麦轮（淘汰）**：麦轮的小辊子与主轮轴线呈45°夹角。虽然能实现全向移动，但小辊子与地面接触面积小，在26\.5°的坡道上极易发生纵向打滑；且遇到场地上的台阶或缝隙时，小辊子容易卡顿，无法提供稳定的牵引力。

- **四全向轮（淘汰）**：全向轮的小辊子轴线与主轮垂直。其表面同样光滑，横向摩擦力极低。在上坡时，一旦车体出现微小的角度偏移，极易发生横向滑移，导致车辆失控，无法在窄桥上保持直线。

- **双胶轮\+双全向轮（淘汰）**：该构型虽然能利用全向轮规避轴向力，但其旋转半径较大（无法原地自旋）。场地空间有限且需要频繁转弯，该构型容易碰壁，且在窄桥上横向极不稳定，严重影响比赛效率。

- **纯四胶轮（最终采用）**：四个刻槽橡胶轮提供了最大的接触面积和摩擦力，抓地力最强，能确保在坡道上不打滑；同时，左右轮差速可实现原地自旋，直线速度快。虽然在2kg负载下高频转向会对电机造成一定的轴向力，但在小体量比赛中影响可控，最终采用。

    

### 1\.3 核心矛盾：四胶轮轴向力问题的探究与解决



在选定四胶轮期间，我们通过查阅资料发现该构型存在一个关键缺陷：

**沿轮轴方向产生的轴向力无法被有效抵消，而是直接传递至电机或减速箱的轴向。** 这一缺陷会引发连锁问题：若仅进行短时间、小幅度的运动，或许不会产生明显影响；但在高频次动作、高负载的实战场景中，这些轴向力会对电机减速箱造成严重损伤，具体表现为设备发出啸叫声、损耗速度加快，最终甚至可能导致完全失效。



**解决方案：**

为了验证这一理论风险，我们向机械组的学长进行了请教，得到了明确的回复：“**小车的体量过小，不必考虑四个胶轮对轮轴的伤害**”。结合我们自身的车辆重量和比赛频次，我们最终决定仍然采用纯四胶轮构型，并在后续电控编程中严格限制原地自旋的频率和速度，以延长电机寿命。

## 2\. 底盘选择



### 2\.1 需求分析



1. **窄桥通过性**：场地的桥梁仅15cm（150mm）宽，这要求底盘的**轮距（左右轮外侧距离）必须≤15cm**，否则直接卡在桥上或跌落。

2. **重量限制**：整车限重2kg，所以底盘材料的密度必须尽可能小，以给机械臂和伸缩杆留出重量预算。

3. **摔车测试**：需要过18cm（180mm）高的自由落体摔车检测，要求底盘材料不能脆，必须具备抗冲击能力。

    

### 2\.2 材料对比与迭代分析



我们对比了四种常见的底盘材料，并进行了详细的利弊权衡：



- **亚克力（待定）**

- *优点*：成品材料多，易切割，激光加工方便。

- *缺点*：材料脆，不耐摔。在180mm摔车测试中，螺丝孔极易产生应力集中而开裂。

- *减震方案推演*：我们进行了初步的减震方案推演（加垫片、多加支撑柱、放置泡棉垫等），但这只能缓解冲击，无法从根本上改变亚克力脆性大的物理特性。待定。

- **铝合金（最终采用）**

    - *优点*：成品材料多，抗压性好，刚度极高，绝对不会因为2kg的重量而弯曲变形，能完美通过180mm摔车测试。

    - *缺点*：较重，尤其我们打算用双层结构，会吃掉很大部分重量预算。

    - *决策*：权衡摔车测试的生存率与轻量化需求，我们最终决定采用铝合金底盘。后续将在抓取装置和结构件上做极致的轻量化设计（如3D打印镂空），以平衡总重。

- **玻纤板（FR4）（淘汰）**

    - *优点*：抗压性好，不易碎裂，且重量轻，是性能上的最优解。

    - *缺点*：需进行定制切割，商家报价4块板子要150元，远超我们新生组400元的报销限额，性价比极低。

    - *结论*：属于不看价格的最优选，但受限于预算，只能放弃。

- **碳纤维（淘汰）**

    - *优点*：轻，强度好。

    - *缺点*：更贵，且导电，加工难度大。

    - *结论*：预算和安全性无法兼顾，放弃。

        

### 2\.3 重心与安全问题



- **重心控制**：铝合金底盘虽重，但我们计划将重量最大的18650电池组紧贴底层底盘安装，以确保整车重心极低。

- **爬坡稳定性**：在26\.5°的坡道上，高重心极易导致后仰翻车。所以采用铝合金底盘更保证稳定性

- **绝缘处理**：由于铝合金导电，一旦电路板或裸露的电线触碰到金属底盘，将瞬间短路烧毁。我们将不撕掉表面的塑料膜层，所有穿过铝合金的螺丝均添加尼龙垫圈，杜绝短路风险。

## 3\. 电机选择



### 3\.1 需求分析



1. **爬坡能力**：需要足够大的扭矩以克服26\.5°的坡道重力分量。

2. **平地速度**：需要在5分钟的比赛时间内，有足够的直线速度以抓取更多能量晶体。

3. **重量限制**：2kg总重限制，要求电机尽可能轻量化。

4. **结构适配**：要能够与底盘结构完美适配，减少二次加工时间。

    

### 3\.2 电机选型对比与迭代



#### 3\.2\.1 减速比与速度/扭矩的权衡



- **初期方案：N20减速电机（1:150/1:298）**

    - *优点*：重量极轻（单重仅10\-15g），金属齿轮抗磨损。

    - *问题*：扭矩较小，虽然能勉强爬坡，但在平地上速度太慢（100转/分钟配合48mm轮子仅有0\.25m/s），在5分钟的比赛里战术效率低下。且淘宝上没有找到能直接适配我们选用的铝合金底盘的N20电机支架，需要大量打孔改装。

- **淘汰方案：TT马达 1:48 / 1:220**

    - *问题*：1:48扭矩太小，爬26\.5°坡会烧毁；1:220扭矩大但速度太慢，无法在有限时间内完成抢方块任务。

- **最终方案：TT马达 1:120（7\.4V超压驱动）**

    - *考量*：1:120是速度与扭矩的黄金折中点。在7\.4V电池驱动下（超压），实际转速可达200转/分钟，平地速度约0\.5m/s，拥有极佳的机动性；同时其扭矩在减速箱放大后，能勉强支撑爬坡。最关键的是，TT马达自带的梯形卡槽完美适配我们选用的铝合金底盘方孔，省去了二次打孔和购买支架的麻烦。

        

#### 3\.2\.2 供电系统与电控兼容性



- **电流测算**：4个TT马达在7\.4V下堵转电流较大（约2\.5A/个），总计可达10A。

- **驱动决策**：放弃电流余量较小的DRV8833驱动板，选用 **TB6612电机驱动模块**，且1个TB6612只带2个TT马达。主电源从7\.4V电池直接接线（不过降压模块），并在驱动板发热芯片上加装铝散热片。

- **降压隔离**：为防止电机启动导致电压骤降干扰主控，底盘电机与STM32主控、抓取结构的舵机采用独立降压供电方案（3A模块给主控，5A模块给舵机）。

- **软件限速**：由于TT马达内部为塑料齿轮，在7\.4V超压下极易扫齿。我们在代码中将PWM最大占空比限制在 **70%** 以内，并加入“软启动”逻辑，严禁操作手长时间满油门堵转。
